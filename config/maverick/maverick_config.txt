# MaverickStation options
#
# Switches for features MaverickStation adds. Each feature that can be turned
# off gets an entry here, next to a short note on what it does.
#
# Flags: write the name to turn it on. Put a # in front to turn it off.
# Other entries: write the name, a space, then the value.
#
# This file is read on server start. Admins can also change entries live with
# View Variables on the config datum.

## Ask new players for their date of birth and ban anyone under the minimum age. Set to 0 to turn it off.
MAVERICK_AGE_GATE 1

## Minimum age to pass the age gate. Cannot be set below 18.
MAVERICK_AGE_GATE_MINIMUM_AGE 18

## Ages above this are treated as a fake answer and banned. Between 60 and 120.
MAVERICK_AGE_GATE_MAXIMUM_AGE 100

## Version of maverick/privacy_policy.txt. Raise it after a meaningful change and every player is asked to agree again.
MAVERICK_PRIVACY_POLICY_VERSION 1

## Round logs and player-linked database history older than this many days are deleted at server start.
## The privacy policy quotes this number, so players are told the real value.
MAVERICK_LOG_RETENTION_DAYS 90

## Uncomment to write PDA messages to a log meant for public release. Off because the privacy policy says we do not publish logs.
#MAVERICK_PUBLIC_LOGGING

## Local test servers: turn game debugging on when someone connects from localhost,
## so runtimes show in the Debug Log chat tab. Only with the localhost admin rank on.
MAVERICK_LOCAL_DEBUG

## Minutes an unpaid citation has before it becomes a Fine Evasion crime and sets arrest status. 0 turns fine evasion off.
MAVERICK_FINE_EVASION_MINUTES 10


## Automapper templates that never load. One template name per line, from the [templates.<name>] keys in
## _maps/bubber/automapper/automapper_config.toml. The station blacksmith rooms are off by default.
MAVERICK_AUTOMAPPER_DISABLED deltastation_blacksmith
MAVERICK_AUTOMAPPER_DISABLED iceboxstation_blacksmith
MAVERICK_AUTOMAPPER_DISABLED metastation_blacksmith

## Uncomment to give the station its Blacksmith job slot. Forging works either way.
#MAVERICK_BLACKSMITH_JOB

## Uncomment to turn the Good Assistant Points punchcard program back on.
#MAVERICK_GOOD_ASSISTANT_POINTS


## Minutes an unpaid citation has before it becomes a Fine Evasion crime and sets arrest status. 0 turns fine evasion off.
MAVERICK_FINE_EVASION_MINUTES 10
